# Nigeria celebrates

> **This platform was built under intense sprint conditions and won **1st Place** at the hackathon hosted by **De Ambassador Global Network** and **AUST Inspire**
> An interactive, high-performance, mobile-first web application engineered to showcase Nigerian talent, drive regional voting engagement, and host weekly real-time live trivia sessions.
Nigeria celebrates is Nigeria's ultimate talent Platform.  It's a dedicated space to upload, showcase, and vote for the best talents across Nigeria, representing your state on national leaderboards, participating in weekly live quizzes, and exploring the legacy of Nigeria's global icons.

## Features

- **Naija Talent Zone**: Upload talents across 11 categories including Music, Football Freestyle, Comedy Skits, Tech Innovation, and more.
- **State Leaderboards & Naija Votes**: Interactive map of Nigeria that lets you rep your state, vote for your favorite talents, and see which state brings the most heat.
- **Weekly Live Quiz**: Test your knowledge of Nigeria every week, compete live, earn points, and climb the national leaderboard.
- **Live Streams**: Go live and stream your talents in real-time using real-time communication tools, or watch others perform.
- **Hall of Legends**: An interactive compendium of Nigeria's global icons who shaped the nation and world history.
- : Admin dashboard to manage posts, users, categories, quiz builder, and nominees.

## Tech Stack

This project was built using modern web technologies to ensure a fast, responsive, and interactive experience:

- **Frontend Framework**: [React (v19)](https://react.dev/)
- **Backend API:** FastAPI (Python)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Live Streaming & Real-time Communication**: [Agora RTC](https://www.agora.io/en/) (`agora-rtc-sdk-ng`, `agora-rtc-react`)
- **Maps & Data Visualization**: [React Simple Maps](https://www.react-simple-maps.io/) & [D3 Scale](https://d3js.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Authentication**: Google OAuth (`@react-oauth/google`)
- **API Requests**: [Axios](https://axios-http.com/)

## Getting Started

### Prerequisites

- Node.js

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
